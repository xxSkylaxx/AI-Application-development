系統架構與專案規格 (PDF)

前後端分離與 OAuth 安全設計

依照《新營區即時路邊停車資訊地圖專案規劃書》系統架構規劃：

[ 使用者 (GitHub Pages) ]
  │
  ├──► (1) GET /parking (HTTPS)
  ▼
[ Cloudflare Worker (Serverless Backend) ]
  │ (保存 TDX Client ID & Client Secret)
  ├──► (2) OAuth 2.0 取得 Access Token
  ├──► (3) 呼叫 TDX 路邊停車 API
  ├──► (4) 篩選台南市新營區座標與格位
  ├──► (5) 設定 快取 (Cache TTL = 60s)
  ▼
[ Leaflet.js 地圖視覺化 (OpenStreetMap) ]
🗺️ 地圖核心分工
  • OpenStreetMap: 提供道路、地標底圖。
  • Leaflet.js: 處理標籤、Marker 繪製與互動 Popup。
  • TDX API: 提供停車格即時經緯度與剩餘數。
🎨 格位狀態視覺定義
  • 🟢 綠色: 有空位 (Available)
  • 🟠 橘色: 剩餘少量 (Low Availability)
  • 🔴 紅色: 已滿 (Full)
  • ⚪ 灰色: 暫無資料 / 暫停營運
